# Ebrar'a, Sevgiyle

Tablet, telefon ve masaüstünde çalışan; Ebrar için hazırlanmış küçük, romantik bir
tek sayfalık site.

## Açmak için

`index.html` dosyasını doğrudan tarayıcıda açabilir veya klasörde aşağıdaki
komutu çalıştırabilirsiniz:

```bash
python3 -m http.server 8000
```

Ardından aynı cihazda `http://localhost:8000` adresine gidin. Tabletten yerel ağ
üzerinden açmak için bilgisayarın yerel IP adresini kullanın:
`http://BILGISAYAR_IP_ADRESI:8000`.
