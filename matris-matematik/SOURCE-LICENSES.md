# Source attribution and external links
Matris contains only resource titles, author/institution attribution, subject metadata, original URLs and descriptions written for this index. It has no PDF/textbook content, lecture transcripts, reproduced exercises or solutions, PDF proxy, document download API or embedded document reader. Each material opens directly from its original source.
